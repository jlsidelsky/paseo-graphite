Prompt presets

The panel's Review, Fix CI and Feedback actions put these in the composer. Slash commands and skills your sessions have (like /code-review) show up next to them on their own. Placeholders: {pr} (#123), {url}, {prs} (one "#n url" line per PR in the review's scope, bottom to top), {checks} (failing checks, for Fix CI), {comment} (the comment, for a comment's Evaluate / Address; empty from the menu). Provider (e.g. claude, codex) preselects that provider's model for a new session. Fix CI uses the first CI preset, and a comment's Evaluate / Address the first of that kind; a skill like /assess-feedback is used instead while that preset is unedited.
