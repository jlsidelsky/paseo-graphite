Paseo for Graphite

Prompt presets

The panel's Review, Fix CI and Feedback actions put these in the composer, over the PRs picked in the panel's scope control (this PR or some or all of its stack). A preset is a prompt, or a slash command (like /code-review) followed by the PRs and your extra instructions. Placeholders: {prs} (one "#n url" line per PR in scope, bottom to top), {pr} (#123) and {url} (the PR you're on), {checks} (failing checks per PR), {comment} (the comment, for a comment's Evaluate / Address; empty from the menu).

Scope overrides the panel's choice; Ask opens the PR picker first. Session: ＋ New on a new worktree of the topmost PR in scope (Review's default), ＋ New on that PR's existing workspace (Fix CI's and Feedback's default), or the session already selected. Model, effort and mode preselect ＋ New. Favorites go to the top of their menu; hidden ones are left out; Order sorts the rest (lowest first). Fix CI runs its first preset, or shows a menu if you have several. A comment's Evaluate / Address uses a favorite, else a skill like /assess-feedback while that kind's first preset is unedited, else that preset.

Discovered commands

Review and feedback commands the panel found in your sessions, by provider. Rename, hide, favorite, reorder, or give them defaults.

Can't reach Paseo, so model, effort and mode lists only show what's saved.

Alerts

For PRs with Paseo sessions. The same settings are under the panel's ⚙; changes save right away.

Inbox

On Graphite's inbox (or a GitHub PR list) the side panel lists the page's PRs by section, each with its sessions. The same settings are under ⚙ Customize there; changes save right away.
